# PFE Outils Financiers - OpenWeb UI

Ce dépôt regroupe les bibliothèques et les outils Python développés pour la plateforme **OpenWeb UI**. Ces scripts ont été réalisés dans le cadre de l'analyse financière pour le Projet de Fin d'Études (PFE) 2026.

## 📌 À propos

L'objectif de ce projet est de fournir des "Tools" (outils) Python prêts à être intégrés dans OpenWeb UI. Ils permettent d'étendre les capacités des modèles de langage (LLMs) en leur donnant accès à des fonctions spécifiques d'analyse et de traitement de données financières.

**Contexte académique :**
* **Année :** PFE 2026
* **Sujet :** #PFE25-T-1012
* **Auteur :** [@GabPncD](https://github.com/GabPncD)

## ⚙️ Prérequis

Pour utiliser les outils de ce dépôt, vous devez disposer de :
* Une instance fonctionnelle d'**[OpenWeb UI](https://github.com/open-webui/open-webui)**.
* Les droits administrateurs sur votre instance (pour ajouter des Tools).
